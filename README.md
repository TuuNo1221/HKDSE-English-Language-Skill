# HKDSE English Writing

An [Agent Skill](https://agentskills.io/specification) for writing practice in Hong Kong Diploma of Secondary Education (HKDSE) English Language. It covers Paper 2 Part A and B, with a separate workflow for Paper 3 integrated writing.

## Install and use

Clone the repository. Copy the `hkdse-english-writing` directory into your harness's skill directory. In Codex, place it under `.agents/skills/` in your project. Use the skill by name or ask for HKDSE writing help. [Codex skills documentation](https://developers.openai.com/codex/skills)

```sh
git clone https://github.com/TuuNoGITHUB/hkdse-english-writing.git
```

Try these prompts.

- “Use hkdse-english-writing to plan this Part A advice email. Map both bullet points before suggesting an opening.”
- “Review my Part B speech for content, language, and organisation. Show the three edits I should make first.”
- “For this Paper 3 task, map the email requirements to my data file and listening notes, then draft the email.”

## Sources

The skill adapts classroom notes on writing formats, informal letters of advice, letters to the editor, persuasive writing, grammar, and Paper 3 planning. The repository contains rewritten guidance and original examples. Exam-format details use the [HKEAA 2027 English Language Assessment Framework](https://www.hkeaa.edu.hk/DocLibrary/HKDSE/Subject_Information/eng_lang/2027hkdse-e-elang.pdf). Use the instructions on the paper you are practising with.
