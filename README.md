# HKDSE English Language Skill

An [Agent Skill](https://agentskills.io/specification) for Hong Kong Diploma of Secondary Education (HKDSE) English Language practice.

| Paper | Skill support |
| --- | --- |
| 1 Reading | Passage analysis, question strategies, worked answers |
| 2 Writing | Guided and extended compositions, genre guidance, and draft feedback |
| 3 Listening and Integrated Skills | Integrated writing from a data file and listening input |
| 4 Speaking | Group interaction, individual responses, and mock practice |

## Install and use

Clone the repository. Copy the `hkdse-english-writing` directory into your harness's skill directory. In Codex, place it under `.agents/skills/` in your project. Use the skill by name or ask for HKDSE English help. [Codex skills documentation](https://developers.openai.com/codex/skills)

```sh
git clone https://github.com/TuuNoGITHUB/hkdse-english-writing.git
```

Try these prompts.

- “Use hkdse-english-writing to solve these Paper 1 questions and explain the clues for each answer.”
- “Use hkdse-english-writing to plan this Part A advice email. Map both bullet points before suggesting an opening.”
- “Review my Part B speech for content, language, and organisation. Show the three edits I should make first.”
- “For this Paper 3 task, map the email requirements to my data file and listening notes, then draft the email.”
- “Run a Paper 4 group discussion mock. Play two other candidates and wait for my reply each turn.”

## Sources

The skill adapts classroom notes on passage decoding and comprehension, writing formats, advice and persuasion, sentence patterns, integrated writing, and speaking. The repository contains rewritten guidance and original examples. Exam-format details use the [HKEAA 2027 English Language Assessment Framework](https://www.hkeaa.edu.hk/DocLibrary/HKDSE/Subject_Information/eng_lang/2027hkdse-e-elang.pdf). Use the instructions on the paper you are practising with.
