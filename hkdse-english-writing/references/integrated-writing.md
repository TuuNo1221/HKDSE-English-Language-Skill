# Paper 3 integrated writing

Use this workflow for the writing tasks supported by a prompt, data file, and listening input. Consult the year-specific instructions for timing and task structure. [HKEAA 2027 framework](https://www.hkeaa.edu.hk/DocLibrary/HKDSE/Subject_Information/eng_lang/2027hkdse-e-elang.pdf)

1. List each deliverable and its writer, reader, purpose, format, and required points. Break compound requests into components. Retain any supplied starter text, required headings, or recipient details.
2. For each point, record the source location (page, message, table, or recording timestamp) and the usable fact. Scan across sources before drafting. The same document may serve several tasks. Irrelevant material can be left out.
3. Confirm status and timing. A tentative plan, confirmed decision, cancellation, and invitation to suggest options require different language. If dates or numbers clash, check whether a later update clearly supersedes the earlier one. If the conflict remains, flag it.
4. Combine relevant facts in the assigned voice. Paraphrase without changing meaning, preserve exact names and figures where required, and convert source language into the deliverable's register. Expand shorthand only when its meaning is clear. A note from a colleague may become a formal sentence in an external email.
5. Check every usable requirement against the finished text and verify names, dates, figures, units, links, and conditions. Keep source labels in the planning notes or feedback unless the deliverable itself calls for attribution.
6. If a source is missing, ask for it when it is necessary for a complete answer. With a partial set, draft the supported portions and list unresolved facts outside the answer. Use clearly marked placeholders only if the user asks for a template or explicitly accepts them.

**Original example.** A task asks the secretary to email teachers about the new room and arrival time. The old timetable lists Room 204 at 3.45 pm, a later caretaker's message confirms the move to Room 108, and the briefing asks teachers to arrive ten minutes early. The email should tell teachers to come to Room 108 by 3.35 pm, provided the revised message changes only the room. If the briefing's time reference is missing, request it before asserting an arrival time.
